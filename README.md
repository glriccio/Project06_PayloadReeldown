# Stratospheric Balloon Payload Reeldown System

## Project Overview
This repository contains the software, hardware designs, documentation, and version control for the Stratospheric Balloon Payload Reeldown System - a senior design project at North Carolina State University.

The system is designed to control the deployment and retrieval of scientific instruments on solar-powered stratospheric balloons, enabling precise instrument positioning and data collection at various altitudes.
