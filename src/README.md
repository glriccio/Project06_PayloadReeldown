# Source Code

This directory contains all software source code for the Payload Reeldown System.

## Directory Structure

### firmware/
Embedded system code for microcontrollers and real-time control systems.
- Motor control algorithms
- Sensor interfacing
- Communication protocols
- Safety systems

### control/
High-level control system software.
- System state management
- Command processing
- Data logging
- User interface components

### utilities/
Helper scripts and utility programs.
- Data processing tools
- Configuration utilities
- Debugging aids
- Testing utilities
