# Getting Started Guide

Welcome to the Stratospheric Balloon Payload Reeldown System project!

## For New Team Members

### 1. Repository Access

First, clone the repository:
```bash
git clone https://github.com/glriccio/Project06_PayloadReeldown.git
cd Project06_PayloadReeldown
```

### 2. Understand the Project Structure

Familiarize yourself with the repository organization:
- `/src` - Source code (firmware, control software, utilities)
- `/hardware` - Hardware designs (mechanical and electrical)
- `/docs` - All project documentation
- `/tests` - Test code and test data
- `/examples` - Example code and usage demonstrations

### 3. Review Documentation

Read the following documents:
1. [README.md](../../README.md) - Project overview
2. [docs/design/project-overview.md](design/project-overview.md) - Detailed project information
3. [CONTRIBUTING.md](../../CONTRIBUTING.md) - Contribution guidelines

### 6. Development Workflow

1. Create a feature branch
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Make your changes
   - Write code
   - Add tests
   - Update documentation

3. Commit your work
   ```bash
   git add .
   git commit -m "[Component] Description of changes"
   ```

4. Push to GitHub
   ```bash
   git push origin feature/your-feature-name
   ```

5. Create a Pull Request
   - Fill out the PR template
   - Request review from team members
   - Address feedback

## Quick Reference

### Common Git Commands
```bash
# Get latest changes
git pull origin main

# Create new branch
git checkout -b feature/my-feature

# Check status
git status

# Stage changes
git add <file>

# Commit changes
git commit -m "Message"

# Push to remote
git push origin <branch-name>
```

### Project Conventions

- **Branch naming:** `feature/`, `bugfix/`, `docs/`, `test/`
- **Commit messages:** `[Component] Brief description`
- **Code style:** Follow existing patterns in the codebase
- **Documentation:** Update docs with code changes
